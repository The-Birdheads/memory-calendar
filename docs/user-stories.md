# ユーザーストーリー

Memory Calendar のユーザーストーリーをまとめるファイルです。
**書式は仮です。** 書きながら使いにくいところを直していきます(書式を変えたときは「更新履歴」に書く)。

用途:
- 何のための機能かを、利用者の視点で一覧できるようにする
- ストーリーと「動作の流れ(どの画面で何をするか)」を見比べて、違和感のある操作や、ずれを見つける
- チュートリアルで何を紹介するか、広告をどこに入れてよいかを決める材料にする
- 実装・テストの「受け入れ条件」の置き場にする(詳細な仕様は `.kiro/specs/shared-calendar/` にあり、こちらは利用者の視点の整理)

> **現在は「たたき台」です。** アプリの現状(実装済みの画面と操作)と仕様書から起こしたもので、内容は確定していません。
> 確認できていない箇所は **(要確認)** と書いてあります。見比べて、違和感があれば直してください。

---

## 1. 書き方のルール

### ID
`領域コード-連番`(3桁)。例: `CAL-001`。一度付けたIDは、ストーリーを消しても使い回さない(欠番はそのままにする)。

### 領域コード
| コード | 領域 |
|---|---|
| ACC | アカウント・ログイン・個人設定 |
| CAL | カレンダー・共有・招待・メンバー・カレンダー表示 |
| EVT | 予定(作成・編集・対象者・リマインド) |
| MEM | 思い出(写真・コメント・振り返り・タイムライン) |
| TAG | タグ |
| TODO | ToDo |
| MEAL | 献立 |
| NTF | 通知 |
| ONB | 初回体験(チュートリアル・案内) |
| ADS | 広告 |
| OTH | その他 |

領域が増えたら、この表に足す。

### 項目の意味
| 項目 | 内容 |
|---|---|
| ストーリー | 「〜として、〜したい。それは〜のため」の形で1〜2文 |
| 動作の流れ | **どの画面で何をするか**を、番号つきで書く。「画面 → 操作 → 結果」の順。確定しているものだけ書く(まだ決まっていないものは空欄、または(案)と書く) |
| 対象 | だれの話か(下の「想定ユーザー」の名前) |
| 優先度 | 高 / 中 / 低 |
| 状態 | 実装済み / 一部実装 / 未実装 / 見送り |
| チュートリアル | 案内する(順序つき)/ 案内しない。案内するなら一言で何を伝えるか |
| 広告 | 広告を出してよい / 出さない(理由)/ 該当なし |
| 受け入れ条件 | 「こうなっていればできた」と言える条件。チェックボックスで書く |
| 留意点 | 審査・プライバシー・制約・関連するストーリーのID など |

**必須は「ストーリー」「優先度」「状態」だけ**です。ほかは分かるときだけ書き、迷うものは空欄(または `-`)でよいです。

### 動作の流れの書き方
- 1行に1つの操作。「[画面名] 〜をタップ → 〜が表示される」の形にそろえる。
- 画面名は、実際の画面の名前(タブ名、モーダルの見出しなど)に合わせる。
- ストーリーの「したい」と、流れの最後の結果が、対応しているか見比べる。対応していなければ、どちらかが不適切。
- 実装済みの機能は、現状の操作をそのまま書く。「こうしたい」という変更案は、(案)をつけて分ける。

### 書き方のコツ
- 1つのストーリーは1つの目的だけにする。「〜して、さらに〜できる」は分ける。
- 受け入れ条件は、画面を見て確かめられる言い方にする(例:「一覧の右側に対象者のアイコンが出る」)。
- 実装済みの機能も書く(チュートリアルの材料になるため)。状態を「実装済み」にしておけばよい。

## 2. 想定ユーザー(仮)

| 名前 | 説明 |
|---|---|
| 調整役 | 家族や友人グループの予定をまとめている人。共有カレンダーを作って招待する側 |
| メンバー | 招待されて参加する人。予定を見る・足す・コメントする |
| ひとり利用 | 個人用カレンダーだけで、予定・思い出・ToDo・献立を記録する人 |

(実際の利用者像に合わせて直す。増やしてもよい)

## 3. 画面の名前(流れの中で使う呼び方)

| 呼び方 | 内容 |
|---|---|
| ログイン画面 / 登録画面 | ログインしていないときに出る画面 |
| カレンダータブ | 下のタブ。月のカレンダー(グリッド表示)と、一覧表示を切り替えられる |
| ToDoタブ | 下のタブ。自分のToDoの一覧 |
| 振り返りタブ | 下のタブ。「年表」と「画像」を切り替えられる |
| 献立タブ | 下のタブ。「予定」と「記録」を切り替えられる |
| 設定(歯車) | カレンダータブの左上の歯車。「カレンダー設定」「タグ設定」「個人設定」を開く |
| 絞り込み | カレンダータブ・振り返りタブなどの右上のボタン。表示を絞り込む |
| 日付の予定一覧 | カレンダーの日付をタップして出る、その日の予定の一覧 |
| 予定の詳細 | 予定をタップして開く画面 |
| 予定を作成 | ＋ボタンで開く、下から出る入力画面 |

## 4. ストーリーの書式(コピーして使う)

```markdown
### XXX-000 タイトル(短く)
- **ストーリー**: 〜として、〜したい。それは〜のため。
- **対象**: 調整役 / メンバー / ひとり利用
- **優先度**: 高 | 中 | 低　**状態**: 実装済み | 一部実装 | 未実装 | 見送り
- **動作の流れ**:
  1. [画面] 〜する → 〜になる
  2. [画面] 〜する → 〜になる
- **チュートリアル**: 案内する(順序 N: 〜と伝える) | 案内しない
- **広告**: 出してよい | 出さない(理由) | 該当なし
- **受け入れ条件**:
  - [ ] 〜
  - [ ] 〜
- **留意点**: 〜
```

## 5. ストーリー一覧

領域ごとに、ID順に並べます。

### ACC アカウント・ログイン・個人設定

### ACC-001 メールアドレスでアカウントを作る
- **ストーリー**: 新しく使う人として、表示名・メールアドレス・パスワードでアカウントを作りたい。それは、予定やカレンダーを保存して、あとから使い続けるため。
- **対象**: 全員
- **優先度**: 高　**状態**: 実装済み
- **動作の流れ**:
  1. [ログイン画面] 「アカウントをお持ちでない方はこちら」をタップ → 登録画面が開く
  2. [登録画面] 表示名・メールアドレス・パスワードを入力し、「登録する」をタップ → アカウントができ、カレンダータブが開く
  3. 登録と同時に、自分専用の個人用カレンダー(「Myカレンダー」)が1つ自動で作られる
- **チュートリアル**: 案内しない(ONB-001 で初回の案内を扱う)
- **広告**: 出さない(登録の邪魔になるため)
- **受け入れ条件**:
  - [ ] 入力に誤りがあると、画面にエラーが出て登録されない
  - [ ] 登録後、ログアウトするまでログイン状態が続く
- **留意点**: 個人用カレンダーは CAL-004

### ACC-002 Apple または Google でログインする
- **ストーリー**: 登録の手間を省きたい人として、Apple または Google のアカウントでログインしたい。それは、パスワードを覚えずに使い始めるため。
- **対象**: 全員
- **優先度**: 高　**状態**: 実装済み
- **動作の流れ**:
  1. [ログイン画面] 「Appleでログイン」または「Googleでログイン」をタップ → 各サービスの確認画面が開く
  2. 確認して許可 → カレンダータブが開く(初めてなら、個人用カレンダーが自動で作られる)
- **広告**: 出さない
- **受け入れ条件**:
  - [ ] Apple の確認画面を閉じた場合は、エラーを出さずにログイン画面に戻る
- **留意点**: App Store の審査(Appleでサインインの提供)に対応している。アカウント削除時は Apple 側の連携も取り消す(ACC-007)

### ACC-003 メールアドレスでログイン・ログアウトする
- **ストーリー**: 登録済みの人として、メールアドレスとパスワードでログインし、必要なときログアウトしたい。それは、自分のデータにだけ安全にアクセスするため。
- **対象**: 全員
- **優先度**: 高　**状態**: 実装済み
- **動作の流れ**:
  1. [ログイン画面] メールアドレスとパスワードを入力し、「ログイン」をタップ → カレンダータブが開く
  2. 誤りがあれば、画面にエラーメッセージが出て、ログインされない
  3. [設定(歯車) → 個人設定] 「ログアウト」をタップ → ログイン画面に戻る
- **受け入れ条件**:
  - [ ] アプリを閉じて開き直しても、ログイン状態が保たれる(再ログイン不要)

### ACC-004 表示名を変える
- **ストーリー**: ユーザーとして、表示名を変えたい。それは、共有カレンダーのメンバーにわかりやすい名前で見えるようにするため。
- **対象**: 全員
- **優先度**: 中　**状態**: 実装済み
- **動作の流れ**:
  1. [設定(歯車) → 個人設定] 「ユーザー名」の鉛筆アイコンをタップ → 入力欄が開く
  2. 名前を直して ✓ をタップ → 保存される(✕ で取り消し)
- **受け入れ条件**:
  - [ ] 空の名前は保存できない
  - [ ] 頭文字のアイコンを使っている場合、新しい名前の頭文字に変わる(ACC-005)

### ACC-005 自分のアイコンを決める
- **ストーリー**: ユーザーとして、自分のアイコンを決めたい。それは、予定の対象者などで、自分が一目で分かるようにするため。
- **対象**: 全員
- **優先度**: 中　**状態**: 実装済み
- **動作の流れ**:
  1. [設定(歯車) → 個人設定] 「アイコン」欄を見る → 初期状態は、ユーザー名の頭文字(色つき)
  2. 「画像を選ぶ」をタップ → 写真の選択画面が開き、正方形に切り抜いて選ぶ → 画像のアイコンに変わる
  3. 「頭文字に戻す」をタップ → 頭文字のアイコンに戻る
- **受け入れ条件**:
  - [ ] 画像のアイコンは、同じカレンダーに参加しているメンバーにだけ見える
  - [ ] ユーザー名を変えると、頭文字のアイコンも変わる
- **留意点**: アイコンは EVT-005(予定の対象者)の一覧で使う。画像は非公開の保存先に置く

### ACC-006 週の開始曜日を選ぶ
- **ストーリー**: ユーザーとして、カレンダーの週を日曜始まりか月曜始まりか選びたい。それは、自分の生活に合う見え方で使うため。
- **対象**: 全員
- **優先度**: 低　**状態**: 実装済み
- **動作の流れ**:
  1. [設定(歯車) → 個人設定] 「週の開始曜日」で「日曜始まり」または「月曜始まり」をタップ → カレンダーに反映される
- **受け入れ条件**:
  - [ ] カレンダータブの曜日の並びが、選んだ開始曜日になる

### ACC-007 アカウントを削除する
- **ストーリー**: ユーザーとして、アカウントを削除したい。それは、使わなくなったときに自分のデータを残さないため。
- **対象**: 全員
- **優先度**: 高　**状態**: 実装済み
- **動作の流れ**:
  1. [設定(歯車) → 個人設定] 「アカウントを削除」をタップ → 確認の画面が出る
  2. (Apple でログインした人のみ)Apple の確認画面が出る → 確認する(閉じると、削除は中止される)
  3. 確認画面で削除を確定 → アカウントとデータが削除され、ログイン画面に戻る
- **受け入れ条件**:
  - [ ] 共有カレンダーに自分しかいなければ、そのカレンダーも削除される
  - [ ] 自分のアイコン画像も削除される
- **留意点**: App Store の審査項目(アプリ内でのアカウント削除)。審査メモに手順を書いてある

### CAL カレンダー・共有・招待・メンバー・カレンダー表示

### CAL-001 共有カレンダーをつくる
- **ストーリー**: 調整役として、家族や友人と使う共有カレンダーをつくりたい。それは、みんなで同じ予定を見られるようにするため。
- **対象**: 調整役
- **優先度**: 高　**状態**: 実装済み
- **動作の流れ**:
  1. [カレンダータブ] 「家族や友人と予定を共有できます / 共有カレンダーを作る」の案内をタップ(または 設定(歯車) → カレンダー設定 → 「新しく作る」) → 作成画面が開く
  2. カレンダー名と色を決めて作成 → 共有カレンダーができる(自分がオーナー)
  3. 「招待する」をタップ → 招待コードの発行へ進む(CAL-002)。「あとで招待する」で閉じることもできる
- **チュートリアル**: 案内する(順序 1: 「まずは共有カレンダーをつくって、家族や友人を招待しましょう」)(案)
- **広告**: 出さない(最初の操作の邪魔になるため)(案)
- **受け入れ条件**:
  - [ ] 名前が空だと作成できない
  - [ ] 作ったカレンダーが、カレンダーの切り替え・絞り込みの一覧に出る
- **留意点**: 招待された人しか見えない(公開の投稿や検索はない)

### CAL-002 招待コードで家族や友人を招待する
- **ストーリー**: 調整役として、招待コードを発行して相手に伝えたい。それは、相手が自分で参加できるようにするため。
- **対象**: 調整役
- **優先度**: 高　**状態**: 実装済み
- **動作の流れ**:
  1. [設定(歯車) → カレンダー設定] 共有カレンダーを選び、「招待する」をタップ → 招待の画面が開く
  2. 「招待コードを発行」をタップ → コードが表示される
  3. 共有ボタンをタップ → 共有メニューから、メッセージなどで相手に送る
- **受け入れ条件**:
  - [ ] コードには有効期限があり、期限が切れると参加できない
  - [ ] 個人用カレンダーには招待できない
- **留意点**: 連打してもコードが複数発行されないようにしてある

### CAL-003 招待コードで共有カレンダーに参加する
- **ストーリー**: メンバーとして、受け取った招待コードで共有カレンダーに参加したい。それは、同じ予定を見られるようにするため。
- **対象**: メンバー
- **優先度**: 高　**状態**: 実装済み
- **動作の流れ**:
  1. [設定(歯車) → カレンダー設定] 「招待コードで参加」をタップ → コード入力欄が開く
  2. コードを入力して参加 → そのカレンダーのメンバーになり、カレンダーの一覧に加わる
- **チュートリアル**: 案内する(順序 1-b: 招待を受けた人向けに「招待コードで参加しましょう」)(案)
- **受け入れ条件**:
  - [ ] コードが誤っている・期限切れのとき、エラーが出る
- **留意点**: 招待リンクでの参加は未対応(コード入力のみ)(要確認: 仕様書には「リンクまたはコード」とある)

### CAL-004 自分専用の個人用カレンダーを使う
- **ストーリー**: ユーザーとして、自分だけの予定を入れる個人用カレンダーを使いたい。それは、他の人に見せない予定・ToDo・思い出も、1つのアプリで管理するため。
- **対象**: ひとり利用 / 全員
- **優先度**: 高　**状態**: 実装済み
- **動作の流れ**:
  1. アカウント作成時に、「Myカレンダー」が自動で1つ作られる
  2. [カレンダータブ] 予定を作るとき、カレンダーとして「Myカレンダー」を選べる
  3. 個人用カレンダーの予定には、鍵のマークが付く
- **受け入れ条件**:
  - [ ] 個人用カレンダーは1人に1つだけで、削除や招待はできない
  - [ ] 個人用カレンダーの予定は他の人に見えない
  - [ ] 個人用カレンダーの予定には、対象者の欄が出ない(EVT-005)

### CAL-005 見たいカレンダーを絞り込む
- **ストーリー**: 複数のカレンダーに参加している人として、見たいカレンダーだけを表示したい。それは、予定が混ざって見づらくならないようにするため。
- **対象**: 全員
- **優先度**: 中　**状態**: 実装済み
- **動作の流れ**:
  1. [カレンダータブ] 右上の絞り込みをタップ → カレンダーの一覧と、色の凡例が開く
  2. 見たいカレンダーを選ぶ → 選んだカレンダーの予定だけが表示される
  3. 絞り込み中は、ボタンが青く塗りつぶされる(リセットで元に戻る)
- **受け入れ条件**:
  - [ ] 絞り込み中だと、一目でわかる(ボタンの見た目が変わる)
  - [ ] 色の凡例で、色とカレンダーやタグの対応がわかる

### CAL-006 カレンダーの色を自分用に決める
- **ストーリー**: メンバーとして、共有カレンダーの色を自分用に選びたい。それは、自分の画面で、予定を見分けやすい色にするため。
- **対象**: メンバー / 調整役
- **優先度**: 中　**状態**: 実装済み
- **動作の流れ**:
  1. [設定(歯車) → カレンダー設定] カレンダーを選ぶ → 色の一覧が出る(「この色はあなたの画面にだけ反映されます」の注記つき)
  2. 色をタップ → すぐに保存され、自分の画面の色が変わる
- **受け入れ条件**:
  - [ ] 色を変えても、他のメンバーの表示色は変わらない
  - [ ] 作成時に決めた色が、メンバー全員の初期の色になる
- **留意点**: タグが付いた予定は、タグの色が優先される

### CAL-007 カレンダー名を変える
- **ストーリー**: メンバーとして、共有カレンダーの名前を変えたい。それは、実態に合った名前にするため。
- **対象**: メンバー / 調整役
- **優先度**: 低　**状態**: 実装済み
- **動作の流れ**:
  1. [設定(歯車) → カレンダー設定] カレンダーを選ぶ → 「カレンダー名」の鉛筆アイコンをタップ
  2. 名前を直して ✓ をタップ → 全員の画面で、名前が変わる
- **留意点**: 名前の変更は、オーナーでなくても、メンバーなら誰でもできる

### CAL-008 カレンダーのメンバーを確認する・外す
- **ストーリー**: 調整役として、カレンダーに誰が参加しているか確認し、必要なら外したい。それは、不要な人に予定を見せ続けないため。
- **対象**: 調整役
- **優先度**: 中　**状態**: 一部実装
- **動作の流れ**:
  1. [設定(歯車) → カレンダー設定] カレンダーを選ぶ → 「所属するユーザー」に、メンバーの名前が一覧で出る(実装済み)
  2. メンバーを外す操作(未実装)(案: 一覧の各行から、オーナーだけが外せる)
- **受け入れ条件**:
  - [ ] メンバー一覧が見られる
  - [ ] (未実装)オーナーがメンバーを外せる
- **留意点**: 外す処理自体は内部にあるが、画面が無い。外したメンバーは、予定の対象者からも自動で外れる

### CAL-009 カレンダーから抜ける・削除する
- **ストーリー**: メンバーとして、共有カレンダーから抜けたい。最後の1人なら、カレンダーごと削除したい。それは、使わなくなったカレンダーを整理するため。
- **対象**: メンバー / 調整役
- **優先度**: 中　**状態**: 実装済み
- **動作の流れ**:

  - [ ] 「00」「30」のキーで、時や分にそのまま入る(時の「30」は無反応)
